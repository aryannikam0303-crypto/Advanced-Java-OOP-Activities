# Advanced Java OOP Programming Questions

This folder contains 10 separate Java source files for advanced-level OOP practice.

## Programs
1. Inheritance and Method Overriding
2. Abstract Class and Interface
3. Runtime Polymorphism
4. Multilevel and Hierarchical Inheritance
5. Exception Handling and User-Defined Exception
6. Multithreading using Thread Class
7. Multithreading using Runnable Interface
8. Collections using ArrayList and HashMap
9. File Handling with Exception Handling
10. Banking Management System using OOP

## How to run
Open a terminal in this folder and compile/run one program at a time:

```bash
javac Program01_Inheritance.java
java Program01_Inheritance
```

Replace the file and class name for the program you want to run. Each file has its own public class and can be compiled independently.

Note: Multithreaded program output order may vary between runs because threads execute concurrently.
