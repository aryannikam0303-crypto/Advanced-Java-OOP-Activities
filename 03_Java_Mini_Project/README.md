# Java Library Management System

## Project Overview
A GUI-based Library Management System developed using Core Java and Java Swing.

## Features
- Admin Login
- Dashboard
- Add and View Books
- Search Books
- Issue and Return Books
- Member Management

## Concepts Used
- Inheritance
- Polymorphism
- Abstraction
- Interfaces
- Encapsulation
- Exception Handling
- Multithreading
- Collections Framework

## Technologies
- Java
- Java Swing
- AWT
- VS Code
