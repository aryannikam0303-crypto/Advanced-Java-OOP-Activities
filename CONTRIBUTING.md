# Collaboration Guidelines

## Project
Library Management System using Java Swing.

## Development Guidelines
1. Use meaningful class and method names.
2. Follow Java OOP principles.
3. Add comments wherever necessary.
4. Handle exceptions properly.
5. Test changes before submitting.

## Code Review Checklist
- Check code readability.
- Verify OOP concepts.
- Check exception handling.
- Verify GUI functionality.
- Suggest improvements before merging.
